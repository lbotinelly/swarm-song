# Bundled typography

Approved by Leo on November 13, 2026. Official Google Fonts files, downloaded November 13, 2026; unmodified.

- Finger Paint Regular (400): https://github.com/google/fonts/tree/main/ofl/fingerpaint — `FingerPaint.ttf`, license `fingerpaint-OFL.txt`. Lyrics and title; no synthetic bold.
- Bitcount Single variable: https://github.com/google/fonts/tree/main/ofl/bitcountsingle — `BitcountSingle.ttf`, license `bitcountsingle-OFL.txt`. Agent-message typography; current caption test uses weight 550 for the existing blue-name outro. Other axes retain defaults.

Both are SIL Open Font License 1.1; copyright and license notices accompany these files. FontFace loads these local files before Remotion captures a frame. No runtime Google Fonts request or font package. Pillow derives lyric widths from the same Finger Paint file.
